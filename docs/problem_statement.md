# Problem Statement

災後重建與防災治理常涉及多個中央部會、地方政府、學術單位與民間團體共同投入。然而，各單位所推動的工程、補助、研究、監測、公民參與與環境復原措施，通常分散於不同網站、新聞稿、公告、補助辦法、採購資料、計畫書與會議紀錄中。

Agency2Map 要解決的是「資源投入資訊分散」問題，讓使用者能快速回答：

- 誰已經投入？
- 投入在哪裡？
- 投入多少？
- 做了什麼？
- 是否與其他計畫重複？
- 哪些區域或議題仍有缺口？
- 資料來源有多可靠？

## Personas

| 使用者 | 需求 |
|---|---|
| 中央或地方主責協調人員 | 快速掌握各部會與地方政府在特定災區的投入情形 |
| 地方政府承辦人員 | 知道中央哪些計畫、補助或工程已進入地方 |
| 防災研究或技術團隊 | 了解不同單位已執行的調查、監測與研究範圍 |
| 公民團體、媒體或在地居民 | 了解災後重建資源是否進入受影響地區 |
| 部會承辦人 | 查詢其他單位是否已做相近工作，避免重複投入 |
