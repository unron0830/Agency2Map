# Publication Review

本文件整理 `data/public_tenders/` 目前蒐集資料的公開建議。目的不是法律意見，而是作為參賽展示與 GitHub 上架前的資料治理檢核。

## 判斷原則

可公開：

- 政府公開招標文件、服務建議書徵求文件、採購公告附件。
- 已在政府網站、公開平台、StoryMap、NCDR 或採購系統可查得之資料。
- 從公開文件整理出的計畫名稱、機關、預算、工項、範圍、日期與來源網址。

不建議公開原檔：

- 自行整理表格原始檔，容易混有未確認來源、個人判斷或非正式備註。
- 會議簡報、協調會資料、內部交換資料，除非確認原始公開來源。
- 含大量地圖、圖表、空拍、剖面圖、掃描頁或報告圖的 PDF，除非確認可再散布。
- 無法確認來源或授權狀態的學術論文、研究報告或 Google Drive 檔案。

建議公開方式：

- 優先公開 `sources.csv`、`resource_items.csv`、`resource_items.geojson` 等整理後 metadata。
- 原始 PDF 若不確定授權，改公開來源網址與摘要，不上傳 PDF 本體。
- 對每筆資料保留 `source_title`、`source_url`、`source_date`、`evidence_text`、`reviewer_note`。

## 建議下一步

1. 將「暫不建議公開原檔」移到 `data/private_docs/`。
2. 由自行整理表格萃取公開欄位到 `sample_data/resource_items.csv`。
3. 對每筆資料新增 `publication_status`：
   - `public_source`
   - `public_metadata`
   - `private_reference`
   - `needs_review`
   - `do_not_publish`
4. WebGIS 預設只讀取 `public_source` 與 `public_metadata`。
5. 對公開 PDF 優先保留來源網址；除非確認可再散布，否則不把 PDF 本體上傳 GitHub。
