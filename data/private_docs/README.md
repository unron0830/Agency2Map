# Private Local Documents

This folder is for local-only source documents that should not be committed to GitHub.

Examples:

- non-public government project reports
- unpublished result reports
- report figures, maps, screenshots, or scanned pages that cannot be redistributed
- documents containing internal review notes, personal data, or unclear publication rights

The `.gitignore` keeps files in this folder out of version control. Keep only this README in GitHub.

Allowed public derivatives:

- document title
- agency name
- public source URL, when available
- high-level metadata
- manually reviewed resource rows
- GeoJSON points or generalized work areas that do not reproduce restricted maps or figures
