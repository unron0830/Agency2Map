# Public Tender Documents

Place government tender, request-for-proposal, and procurement-related files here when they are publicly searchable or otherwise lawful to publish.

This folder is intended for files that may contain:

- project amount or budget ceiling
- work items
- expected service scope
- study or engineering area
- tendering agency
- procurement or announcement metadata

Recommended filename pattern:

```text
YYYYMMDD_agency_project-name_source.pdf
YYYYMMDD_agency_project-name_extracted.csv
```

## Publication Rule

Only add files that are public tender documents or public procurement records. Do not add non-public reports, internal working files, unpublished result reports, restricted attachments, personal data, or copyrighted figures from local report PDFs.

If a local document is useful but not public, extract only reviewable metadata into `sample_data/` or `data/processed/`, and keep the original file under `data/private_docs/`.
